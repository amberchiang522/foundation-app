# 志工管理系統 - 操作手冊

---

## 1. 志工申請流程

### 申請步驟（前台）

**網址：** `/apply`

1. 閱讀並同意服務條款
2. 填寫申請表單
   - 姓名、生日、手機、職業
   - Email（登入帳號）、LINE ID
   - 服務經驗
3. 提交申請，等待審核

### 查詢申請狀態

**網址：** `/apply/status`

- 輸入 Email 查詢進度
- 狀態：審核中 / 已通過 / 未通過 / 需補件

---

## 2. 帳號建立流程（Supabase）

### 步驟總覽

```
申請人送出申請 → 管理員審核通過 → Supabase 建立帳號 → 通知申請人登入
```

### Step 1：審核通過申請

**系統路徑：** 後台 → 申請審核 (`/dashboard/applications`)

1. 點擊待審核的申請卡片
2. 確認申請資料無誤
3. 點擊「通過」按鈕

### Step 2：登入 Supabase Dashboard

1. 前往 [Supabase Dashboard](https://supabase.com/dashboard)
2. 選擇專案 (foundation-app)
3. 左側選單點擊 **Authentication**

### Step 3：建立使用者帳號

1. 點擊 **Users** 標籤
2. 點擊右上角 **Add user** → **Create new user**
3. 填寫資料：

| 欄位 | 填寫內容 |
|------|----------|
| Email | 申請人的 Email |
| Password | 申請人的手機號碼（預設密碼） |
| Auto Confirm User | ✓ 打勾（自動驗證） |

4. 點擊 **Create user**

### Step 4：補充 User Metadata（選填）

建立用戶後，點擊該用戶進入編輯：

1. 在 **User Metadata** 區塊點擊編輯
2. 輸入以下 JSON：

```json
{
  "name": "申請人姓名",
  "phone": "0912345678",
  "birthday": "1995-03-15"
}
```

3. 儲存

> 系統會自動根據 metadata 建立 profiles 資料並產生志工編號

### Step 5：通知申請人

告知申請人：
- 帳號：申請時的 Email
- 密碼：申請時的手機號碼
- 登入網址：`/login`

| 項目 | 說明 |
|------|------|
| 帳號 | 申請時的 Email |
| 密碼 | 申請時的手機號碼 |

輸入 Email 與密碼登入後台。

## 4. 後台管理

### 4.1 志工申請審核

**路徑：** 後台 → 申請審核

**操作：**
1. 查看待審核列表
2. 點擊「審核」查看詳情
3. 選擇操作：
   - **通過** → 前往 Supabase 建立帳號
   - **要求補件** → 填寫補件說明
   - **拒絕** → 填寫拒絕原因

---

### 4.2 志工管理

**路徑：** 後台 → 志工管理

**操作：**
- 搜尋：姓名、Email、編號、電話
- 篩選：類型（青年/社會）、狀態（正常/停權）
- 點擊志工查看詳情與活動紀錄
- 停權 / 恢復志工帳號

---

### 4.3 計畫管理

**路徑：** 後台 → 計畫管理

**新增計畫：**
1. 點擊「新增計畫」
2. 填寫：計畫名稱、說明、類型
3. 設定公開選項（選填）：封面圖、公開說明、PDF
4. 設定工作流程步驟（選填）
5. 儲存

**其他操作：** 編輯 / 封存

---

### 4.4 專案管理

**路徑：** 後台 → 專案管理

**新增專案：**
1. 點擊「新增專案」
2. 選擇所屬計畫
3. 填寫：專案名稱、描述、類型、預算
4. 建立（自動繼承計畫工作流程）

**執行審批：**
1. 開啟專案詳情
2. 在當前步驟點擊「審批」
3. 填寫備註，選擇通過或拒絕

---

### 4.5 活動管理

**路徑：** 後台 → 活動管理

**新增活動：**
1. 點擊「新增活動」
2. 填寫：名稱、說明、日期、地點、類型、人數上限
3. 選擇報名方式：直接報名 / 審核報名
4. 上傳封面圖
5. 儲存

**報名管理：**
1. 點擊「查看報名」
2. 審核待核准的報名
3. 活動結束後記錄出席與服務時數

**新增活動回顧：**
1. 在已結束活動點擊「新增回顧」
2. 填寫標題、內容、上傳照片
3. 至「活動回顧管理」發布

---

### 4.6 帳號權限管理

**路徑：** 後台 → 帳號管理（僅超級管理員）

**變更角色：**
1. 找到用戶，點擊「編輯」
2. 選擇角色：志工 / 內部人員 / 管理員 / 超級管理員
3. 儲存

**管理 Admin Tag：**
1. 新增 Tag（如：財務審核、專案審批）
2. 指派 Tag 給管理員
3. 在計畫工作流程中設定審批步驟需要的 Tag
